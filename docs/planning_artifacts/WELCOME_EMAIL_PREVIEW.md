## 🎨 Design Features

### Color Scheme
- **Background**: Black (#0A0A0A, #111111)
- **Primary**: Green (#14B8A6)
- **Text**: White (#FFFFFF), Gray (#CCCCCC, #999999)
- **Accent**: Dark Gray (#1A1A1A)

### Typography
- **Headers**: Bold, Italic, Uppercase
- **Body**: Regular, 16px, Line height 1.8
- **Labels**: Uppercase, Letter spacing 0.2em

### Layout
- **Max Width**: 600px (mobile-friendly)
- **Padding**: 30-40px
- **Border Radius**: 15-20px
- **Responsive**: Adapts to all screen sizes

### Interactive Elements
- **Buttons**: Green background, black text, hover effects
- **Links**: Green color, no underline
- **Icons**: Emoji for visual appeal
